# Changelog

All Notable changes to the **Symfony Bundle Syslog** project.

## [3.0.0]

### Added

- Added support for Symfony 6 & 7.
- Added support for PHP 8.3+

### Changed

- Change configuration from service.yml to .env files.

### Removed

- Support for Symfony 5 and lower.
- Support for PHP 8.2 and lower.
